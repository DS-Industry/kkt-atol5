ПОЛНОЕ ОБНОВЛЕНИЕ kkt-atol5 — 25.08.2026
================================================

Этот архив заменяет предыдущий неполный архив. В нём есть весь код,
все HTML-шаблоны (включая templates/admin/base.html), тесты и документация.

ЧТО ИСПРАВЛЕНО
---------------
1. В Admin → Settings добавлен выбор налога:
   - Без НДС
   - НДС 0%
   - НДС 5%
   - НДС 7%
   - НДС 10%
   - НДС 22%

2. По умолчанию выбрано «Без НДС».

3. Для «Без НДС» в receiptTax передаётся полная сумма чека, а не 0.
   Это исправляет ошибку АТОЛ 128 «Некорректная сумма налога».

4. Ставка передаётся и позиции товара, и итогу чека. Новая настройка
   применяется к следующему чеку без переподключения к ККТ.

5. В настройках можно указать имя и ИНН кассира. Имя печатается на
   следующих чеках. ИНН должен состоять ровно из 12 цифр.

6. Старое значение HTTP-порта 5050 автоматически заменяется на 5000
   при запуске. После сохранения Settings значение 5000 запишется в
   instance/config.json.

7. История хранит до 1000 чеков. В ней показываются QR generated,
   полный QR и дата/время чека по Москве.

ВАЖНО ПЕРЕД ОБНОВЛЕНИЕМ
-----------------------
- Одновременно должен работать только ОДИН процесс kkt-atol5.
- Не удаляйте папку instance: в ней база чеков и ваши настройки.
- Сначала остановите старую программу.

Если раньше в списке был PID 3466, сначала проверьте, что это именно
старая программа kkt-atol5:

  ps -fp 3466
  sudo tr '\0' ' ' < /proc/3466/cmdline
  echo

Если это kkt-atol5, остановите его штатным способом. Для systemd:

  sudo systemctl stop kkt-atol5

Если программа была запущена вручную — вернитесь в её терминал и нажмите
Ctrl+C. Не запускайте вторую копию поверх первой.

УСТАНОВКА
---------
Ниже пример, если проект находится в /home/orangepi/Desktop/kkt-atol5,
а архив скачан в /home/orangepi/Downloads.

1. Сделайте резервную копию базы и настроек:

  cp -a /home/orangepi/Desktop/kkt-atol5/instance \
        /home/orangepi/Desktop/kkt-atol5-instance-backup

2. Распакуйте архив ПОВЕРХ существующей папки проекта:

  unzip -o /home/orangepi/Downloads/kkt-atol5-FULL-update-2026-08-25.zip \
        -d /home/orangepi/Desktop

Архив не содержит папку instance и поэтому не заменяет вашу базу и конфиг.

3. При необходимости установите зависимости:

  cd /home/orangepi/Desktop/kkt-atol5
  python3 -m pip install -r requirements.txt

4. Запустите только одну копию программы:

  cd /home/orangepi/Desktop/kkt-atol5
  python3 main.py

Либо, если у вас настроен systemd:

  sudo systemctl start kkt-atol5
  sudo systemctl status kkt-atol5 --no-pager

5. Проверьте порт:

  sudo ss -ltnp | grep ':5000'

НАСТРОЙКА НАЛОГА И КАССИРА
--------------------------
1. Откройте:

  http://IP_ORANGE_PI:5000/admin/settings

2. Поля «Кассир на чеке», «ИНН кассира» и «Налоговая ставка на чеке»
   находятся сразу после поля Library path.

3. Выберите ставку, которая соответствует регистрации вашей организации.
   Если ваша касса работает без НДС, оставьте «Без НДС».
   Для ставок 5%, 7% и 22% драйвер и прошивка ККТ должны поддерживать эту ставку.

4. Нажмите Save. Переподключение для изменения налога или кассира не нужно.
   Для изменения USB/TCP используйте Save & reconnect.

5. Сначала напечатайте ровно ОДИН тестовый чек и проверьте на бумаге:
   кассира, ставку, сумму, дату/время и QR.

ЗАПИСИ 2–9 ИЗ ПРЕДЫДУЩЕГО ЛОГА
------------------------------
Чеки с ошибкой 128 были отменены через cancelReceipt и отмечены failed.
Не отправляйте их автоматически повторно. После обновления создайте один
новый тестовый чек.
